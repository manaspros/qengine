Write a Python command-line tool that reads a large CSV file of web server access logs (columns: timestamp, ip, method, path, status, bytes, duration_ms), and prints a report: requests per minute, the ten slowest endpoints by median duration, status code counts, and the top client IPs by bytes transferred. Stream the file instead of loading it into memory, use only the standard library, add argparse options for the input path and a time window, include type hints and docstrings, and add unit tests with unittest for the parsing and aggregation functions.
