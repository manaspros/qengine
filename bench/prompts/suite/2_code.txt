Write a complete Python module that implements an LRU cache with per-entry time-to-live expiry. Requirements: a class TTLCache with methods get(key, default=None), set(key, value, ttl=None), delete(key), clear() and __len__; a max_size after which the least recently used entry is evicted in O(1) time; expired entries are never returned and are purged lazily on access and by a purge_expired() method. Use collections.OrderedDict and time.monotonic, add type hints and docstrings, and make it thread-safe with a threading.Lock. Then write a pytest file that covers eviction order, TTL expiry (with a fake clock passed to the constructor), overwriting keys and deleting missing keys. Show the full code for both files.
